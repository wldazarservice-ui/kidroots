# Mokalibo — Campagne Google Ads (prête à copier)

Budget de départ : **7 €/jour** (4 € France/francophones + 3 € Allemagne/germanophones), soit ≈ 210 €/mois.
On regarde les chiffres après **5 jours**, pas avant.

---

## 1. Créer le compte (10 min)

1. Va sur **https://ads.google.com** → « Commencer ».
2. Google pousse une « campagne intelligente » : en bas de l'écran, clique **« Passer en mode Expert »**
   (ou « Créer un compte sans campagne »). Le mode Expert est indispensable pour suivre ce plan.
3. Pays de facturation : **Allemagne**, fuseau : **Berlin**, devise : **EUR**.
4. Ajoute **ta** carte (Facturation → Moyens de paiement).
5. Google demandera plus tard de **valider l'annonceur** (pièce d'identité) : c'est normal, fais-le quand il le demande.

## 4. Suivre les résultats

- Tableau de bord Mokalibo → ligne **Sources** → `google` : visites, essais sans compte, comptes créés.
- Dans Google Ads : regarder le **CPC moyen** et le **taux de clic (CTR)**.
- Règles :
  - CTR < 3 % après 5 jours → changer les titres.
  - Un mot-clé qui coûte > 5 € sans aucun essai → le mettre en pause.
  - Si 1 abonné coûte moins de 10 € → augmenter le budget de 20 % tous les 3 jours.
- Pas de suivi de conversion Google pour l'instant (il faudrait un bandeau cookies RGPD) :
  on mesure avec `utm_source=google` dans le tableau de bord Mokalibo, sans traceur.
